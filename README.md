# Telegram-бот-магазин цифровых товаров

Бот-витрина с автоматической выдачей товара после подтверждения оплаты.
Подходит для продажи ключей, аккаунтов, конфигов, гайдов — любых цифровых товаров,
которые можно отправить текстом.

## Что умеет

- Каталог товаров с ценами и остатком на складе
- Покупка: выдаёт реквизиты → покупатель присылает чек → админ жмёт одну кнопку →
  бот автоматически отправляет товар покупателю
- Склад: товары загружаются списком, каждая продажа списывает одну позицию
- Админ-панель: добавить/убрать товар, пополнить склад, ожидающие заказы,
  статистика продаж (шт. и сумма)

## Быстрый запуск

```bash
pip install -r requirements.txt
```

1. Создай бота у @BotFather → получи токен.
2. Узнай свой Telegram ID у @userinfobot.
3. Задай переменные окружения (или впиши прямо в `config.py`):

```bash
export BOT_TOKEN="123:abc"
export ADMIN_ID="123456789"
export PAYMENT_DETAILS="Карта: 0000 0000 0000 0000 (Имя)"
export SHOP_NAME="Мой магазин"
python3 bot.py
```

4. В боте: `/admin` → ➕ Добавить товар → 📦 Пополнить склад (каждый товар с новой строки).

## Как работает покупка

1. Покупатель жмёт «Купить» → получает реквизиты.
2. Присылает скрин/текст чека → чек прилетает админу с кнопками «Выдать товар» / «Отклонить».
3. Админ жмёт «Выдать» → бот берёт одну позицию со склада и шлёт её покупателю.

Оплата проверяется вручную — это намеренно: без автоматики не нужны платёжные
ключи, а продавец не отдаёт товар без реальной оплаты. Автоматизацию оплаты
(ЮKassa, CryptoBot, СБП) можно добавить за отдельную плату.

## Продажа как шаблона

Каждая копия = свой токен + свои реквизиты + своё название. Всё настраивается
переменными окружения, код трогать не нужно.
